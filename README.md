# DeskCalendar 🗓️

A simple, installable desktop calendar application similar to Outlook Work Week view.

## ✨ Features

- Work Week (Monday–Friday) view
- Hour-based time grid
- Event blocks
- Clean desktop UI
- Lightweight & offline

## 🖥️ Target Users

- Non-technical users
- Office teams
- Personal scheduling users

## 🚀 Goal

Build a desktop application that:
- Installs easily
- Opens with one click
- Works without internet
- Provides a simple scheduling tool

## 🛠️ Tech Stack

- C#
- WPF (.NET)
- Local JSON storage
- Inno Setup (Installer)

---

## 📦 Installation (Planned)

1. Download `SetupDeskCalendar.exe`
2. Run installer
3. Open from Desktop icon
